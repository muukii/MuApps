
# Thoughts (Journal App)

## Concept

* その時の気分や気持ちや考えをサッと記録する
* その表現方法はテキストだけとは限らないので、さまざまな表現手法を提供する
  * テキスト
  * 音
  * 写真
  * 手書き
  * Bauhaus
* コンテンツごとに、その表現に合った見た目と振る舞いを持つ
  * 共通のカード形状へ押し込めない
  * それらはThreadのように繋ぐことができる

## Feature

* 振り返り
  * それぞれのコンテンツを、その表現に合った画像や動画として書き出せる
  * Photosに保存することでPhotosが振り返りに使ってくれる
- Sharing
  - デザイン的には洗練されたものを採用してInstagram Storiesにシェアできるようなものにする
    - 北欧のテイストを基本の軸とする
